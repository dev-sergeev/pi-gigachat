# Протокол GigaChat принадлежит официальному SDK

Самостоятельная реализация протокола заставляет расширение сопровождать изменения API GigaChat. Согласовано передать обращения к API, авторизацию и разбор SSE официальному npm-пакету `gigachat`, сохранив в адаптере преобразование данных и событий Pi, очередь генераций и ограниченные повторы вызовов SDK при временных ошибках. Обёртка не отправляет собственные HTTP-запросы и не содержит обходного транспорта; это сохраняет управление выполнением без дублирования протокола.

Это решение о границе ответственности; миграция ещё не реализована. Требования к совместимости и детали управления выполнением уточняются в проектной сессии.

Сертификатную авторизацию подключения (mTLS) добавляем в существующий транспорт на Undici, не объединяя эту задачу с переносом HTTP, авторизации и SSE на SDK. Это явное исключение до завершения миграции: оно сохраняет границы задачи и не делает поддержку mTLS зависимой от переноса остальных способов авторизации. Запрет собственного транспорта относится к целевому состоянию после миграции; сама целевая граница остаётся в силе.

Объединение pi-gigachat с pi-gigachat-openai и добавление GigaChat V2 также выполняются на существующем транспорте, независимо от миграции на SDK. Это расширяет временное исключение на три протокольных адаптера общего пакета: новая функциональность не ждёт доработки SDK. Цель миграции не отменена, но её выполнимость и применимость к каждому протоколу уточняются в отдельной задаче; полноценная поддержка V2 исследованной версией `gigachat@0.0.20` не подтверждена. Связанные продуктовые решения: [протокол API подключения](0003-connection-api-protocol.md); первичные источники и ограничения проверки: [исследование V2](../research/gigachat-v2-api.md).
