# Интеграция Pi с GigaChat

Расширение предоставляет моделям GigaChat доступ к диалогам и инструментам Pi.

## Language

**Подключение сервера**:
Независимая пользовательская запись, связывающая сервер GigaChat с собственной авторизацией, одним протоколом API и набором выбранных моделей.
_Avoid_: подключение модели, учётная запись

**Протокол API**:
Формат обмена сообщениями с сервером, выбранный для конкретного подключения: GigaChat V1, GigaChat V2 или OpenAI-compatible. Един для всех выбранных моделей этого подключения и не является способом авторизации.
_Avoid_: способ авторизации, общий режим пакета

**Основной endpoint**:
Базовый адрес генерации ответов через протокол API подключения сервера. Не определяет независимо задаваемый адрес каталога моделей.
_Avoid_: адрес каталога моделей

**Адрес каталога моделей**:
Независимо настраиваемый полный адрес получения списка моделей подключения сервера. Его изменение не меняет основной endpoint или способ авторизации подключения.
_Avoid_: основной endpoint, адрес генерации

**Модель сервера**:
Модель, которую конкретный сервер обозначает своим Model ID. Несколько подключений могут обращаться к одной модели сервера.
_Avoid_: подключение сервера

**Название подключения**:
Пользовательское имя подключения сервера, учитывающее регистр и определяющее идентичность нового подключения. Переименование означает замену подключения; прежние подключения могут сохранять одинаковые названия.
_Avoid_: Model ID, идентификатор подключения

**Идентификатор подключения**:
Уникальное обозначение подключения сервера, к которому относятся его авторизация и ссылки на выбранные модели. Отличается от названия у прежних подключений; для новых определяется названием с учётом регистра.
_Avoid_: Model ID, название подключения

**Обновление подключения**:
Изменение адреса, авторизации, протокола API или выбранных моделей без изменения названия и идентичности подключения.
_Avoid_: переименование, замена подключения

**Замена подключения при переименовании**:
Новое подключение с новым названием и идентичностью вместо прежнего; не является обновлением прежней идентичности.
_Avoid_: обновление подключения, миграция истории

**Способ авторизации подключения**:
Механизм доступа подключения к серверу: токен доступа, получение токенов по авторизационному ключу или сертификатная авторизация. Выбирается независимо от протокола API.
_Avoid_: протокол API, тип подключения

**Авторизационный ключ**:
Секрет, позволяющий получать временные токены доступа для подключения сервера; сам ключ не является токеном доступа.
_Avoid_: API token, пароль

**Токен доступа**:
Секрет, разрешающий обращения к GigaChat API от имени владельца подключения сервера.
_Avoid_: авторизационный ключ, credentials

**Сертификатная авторизация подключения**:
Способ авторизации подключения сервера по клиентскому сертификату и соответствующему приватному ключу без токена доступа и авторизационного ключа.
_Avoid_: авторизационный ключ, токен доступа, сертификат сервера

**Выбранная модель подключения**:
Модель сервера, которую пользователь включил в свой список используемых моделей через конкретное подключение сервера.
_Avoid_: подключение сервера

**Проверенная модель**:
Модель сервера, для которой подтверждена возможность генерации с авторизацией и протоколом API конкретного подключения. Проверка генерации не подтверждает поддержку инструментов Pi.
_Avoid_: полностью совместимая модель

**Недоступная по проверке модель**:
Модель сервера, для которой текущая проверка через конкретное подключение не подтвердила возможность генерации после исчерпания попыток. Этот результат не означает недоступность через другие подключения или при последующих проверках.
_Avoid_: глобально недоступная модель, удалённая модель

**Дубль модели**:
Повтор одного Model ID в наборе моделей одного подключения сервера. Одинаковый Model ID у разных подключений обозначает отдельные варианты выбора, а не дубль.
_Avoid_: альтернативное подключение

**Уровень рассуждений**:
Выбранная интенсивность рассуждений при новой генерации; доступные уровни определяются протоколом API и возможностями модели. Не определяет повторную передачу ранее сохранённых рассуждений.
_Avoid_: сохранённые рассуждения, повторная передача рассуждений

**Сохранённые рассуждения**:
Отдельная от текста ответа часть сообщения ассистента в истории Pi, содержащая доступные рассуждения модели. Не является новым ответом или пользовательской инструкцией.
_Avoid_: текст ответа, системная инструкция

**Повторная передача рассуждений**:
Включение доступных сохранённых рассуждений в контекст последующего запроса к модели. Не означает повторную генерацию рассуждений и не изменяет сохранённую историю.
_Avoid_: новая генерация рассуждений, переписывание истории

**Инструкция восстановления генерации**:
Временное сообщение для GigaChat V1 с требованием вызывать не более одного инструмента за сообщение ассистента и ждать его результата перед следующим вызовом. Относится только к повторным попыткам одной генерации после ошибки 422 и не является частью истории диалога.
_Avoid_: сообщение пользователя в истории, постоянная системная инструкция
